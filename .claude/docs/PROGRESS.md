- 2026-06-22 — **P1 backend toolchain (owner-confirmed, sets the pattern for every NestJS service):** the first app `apps/api-gateway` is **NestJS 11, ESM (`type:module`, `module:nodenext`), transpiled by SWC** (`.swcrc` `decoratorMetadata:true`) — esbuild/tsx do NOT emit decorator metadata so they'd break Nest DI. **Hand-rolled** (no `@nx/nest`/`@nx/node` generators) to avoid webpack/CJS config fighting the TS-solution. Dev hot-reload = `swc --watch` (needs **`chokidar`**, added as a root devDep) + `node --watch` via an `nx:run-commands` `serve` target. `tsc` is typecheck-only; SWC owns the runtime `dist`. App tsconfig adds `experimentalDecorators`+`emitDecoratorMetadata`; libs consumed via built `dist` at runtime (`dependsOn:["^build"]`) and `@sanad/source` for typecheck.
- 2026-06-22 — **P1 dev-infra decisions:** one Postgres container with **one database per service + a `*_test` DB each** (`identity/settings/media/content/notifications` ×2) created by `infra/postgres/init/01-create-databases.sql` (MS5/TDD2). Published host ports are offset into a **Sanad-only block** (nginx 8190, pg 5440, redis 6390, rabbitmq 5680/15680, gateway 3010) so they never collide with other projects' containers; all `${VAR:-default}`-overridable. Compose supplies inline dev defaults so `up` boots with no env file; real `.env.*` are gitignored, `infra/.env.example` committed. Health endpoint returns the real **3-field** envelope (`path`/`timestamp` are a P2 interceptor, not added now).
- 2026-06-21 — **P0 scope decision:** the shared libs ship their **framework-agnostic core + typed contracts** (Zod schemas, env accessor, DateTime, model-config, Outbox/idempotency, RBAC policy, design tokens) fully TDD-tested. The **NestJS adapters** named in the P0 task list (JWT guard, RMQ transport client, response interceptor/exception filter/Zod pipe, terminus health) are deferred to **P1/P2**, where a running gateway/service can validate them — rather than shipping untested decorator code now.
